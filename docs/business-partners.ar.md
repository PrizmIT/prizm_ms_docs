# شركاء الأعمال

يوفر وحدة **شركاء الأعمال** سجلاً مركزياً لإدارة جميع الشركات التي تتعامل معها مؤسستك — سواء كانوا عملاء أو موردين أو كليهما. يعمل على إزالة الإدخالات المكررة، وتنظيم الشركات في مجموعات، ويتضمن إثراء بيانات مدعوم بالذكاء الاصطناعي لملء تفاصيل الشركاء تلقائياً.

---

## الوصول إلى الوحدة

انتقل إلى **شركاء الأعمال** من قائمة الشريط الجانبي الأيسر. تحتوي الوحدة على أربعة أقسام فرعية:

| القائمة الفرعية | الوصف |
|----------|-------------|
| **شركاء الأعمال** | القائمة الرئيسية لجميع الشركاء |
| **مجموعة الأسماء** | تجميع الشركات الأم وأداة الدمج |
| **تتبع إثراء الذكاء الاصطناعي** | مراقبة حالة إثراء البيانات بالذكاء الاصطناعي |
| **سجلات عمليات الذكاء الاصطناعي** | سجل المراجعة لجميع عمليات الذكاء الاصطناعي |

---

## قائمة شركاء الأعمال

تعرض الواجهة الرئيسية جميع شركاء الأعمال في جدول AG Grid تفاعلي بالأعمدة التالية:

| العمود | الوصف |
|--------|-------------|
| **#** | المعرف الفريد |
| **الشركة** | اسم الشركة |
| **البريد الإلكتروني** | عنوان البريد الإلكتروني للتواصل |
| **عميل** | هل تم تصنيف هذا الشريك كعميل |
| **مورد** | هل تم تصنيف هذا الشريك كمورد |

### إجراءات شريط الأدوات

- **إضافة شركاء أعمال** — إنشاء سجل شريك جديد
- **سجلات المحذوفات** — عرض الشركاء المحذوفين مؤقتاً والتي يمكن استعادتها

### التصفية

استخدم نظام **التصفية المتقدمة** لبناء استعلامات مخصصة:

- التصفية حسب **الشركة**، **البريد الإلكتروني**، حالة **العميل/المورد**، **تواريخ الإنشاء/التحديث**
- حفظ الفلاتر لإعادة الاستخدام
- مشاركة الفلاتر مع أعضاء الفريق الآخرين
- تعيين فلتر افتراضي يُحمّل تلقائياً

---

## إضافة شريك أعمال

1. انقر على **إضافة شركاء أعمال** من شريط الأدوات
2. املأ النموذج:
    - **الشركة** — اسم الشركة (يجب أن يكون فريداً)
    - **البريد الإلكتروني** — عنوان البريد الإلكتروني للتواصل
    - مفتاح **العميل** — تصنيف كعميل (يُنشئ تلقائياً سجلاً في جدول العملاء)
    - مفتاح **المورد** — تصنيف كمورد (يُنشئ تلقائياً سجلاً في جدول الموردين)
3. انقر على **إرسال**

!!! info "المزامنة التلقائية"
    عند تفعيل مفتاح **العميل** أو **المورد**، يقوم النظام تلقائياً بإنشاء السجل المقابل في جداول العملاء أو الموردين الداخلية. هذا يضمن توفر الشريك عبر جميع الوحدات ذات الصلة (المشتريات، المناقصات، إلخ).

---

## تعديل شريك أعمال

1. انقر على سجل الشريك في القائمة
2. عدّل أي حقول (اسم الشركة، البريد الإلكتروني، حالة العميل/المورد)
3. انقر على **إرسال** لحفظ التغييرات

---

## الحذف والاستعادة

### الحذف المؤقت
- انقر على إجراء الحذف على سجل الشريك
- يُنقل الشريك إلى **سلة المحذوفات** (حذف مؤقت مع طابع زمني)
- لن يظهر بعد ذلك في القائمة الرئيسية

### الاستعادة
1. انقر على **سجلات المحذوفات** من شريط الأدوات
2. ابحث عن الشريك المحذوف في قائمة المحذوفات
3. انقر على **استعادة** لإعادته إلى القائمة النشطة

---

## مجموعات الأسماء

تتيح لك ميزة **مجموعة الأسماء** تنظيم الشركات تحت اسم أم ودمج الإدخالات المكررة.

### لماذا تستخدم مجموعات الأسماء؟

بمرور الوقت، قد يتم إدخال نفس الشركة بتباينات طفيفة (مثال: "شركة أكمي"، "أكمي للمقاولات"، "ACME"). تتيح لك مجموعات الأسماء توحيدها تحت كيان أم واحد.

### إنشاء مجموعة أسماء

1. انتقل إلى **شركاء الأعمال > مجموعة الأسماء**
2. انقر على **عنصر جديد**
3. أدخل **الاسم الرئيسي** للمجموعة
4. انقر على **إرسال**

### دمج الشركات

1. حدد أسماء شركات متعددة من القائمة
2. اختر **الاسم الرئيسي** المستهدف للدمج تحته
3. انقر على **دمج**

!!! warning "تأثيرات الدمج"
    يُحدّث الدمج اسم الشركة عبر جميع الجداول ذات الصلة:

    - جدول **شركاء الأعمال**
    - جدول **المناقصات** (اسم المناقص)
    - جدول **العملاء** (الشركة)
    - جدول **الموردين** (الشركة)

    يتم إنشاء سجلات فرعية لتتبع الأسماء الأصلية لأغراض المراجعة.

### سجلات المحذوفات (مجموعات الأسماء)

يمكن عرض مجموعات الأسماء المحذوفة واستعادتها من سلة محذوفات مجموعة الأسماء، المتاحة عبر زر **سجلات المحذوفات**.

## إثراء الذكاء الاصطناعي

تتضمن الوحدة نظاماً مدعوماً بالذكاء الاصطناعي يُثري بيانات شركاء الأعمال تلقائياً.

### كيف يعمل

1. **جلب البريد الإلكتروني** — يتصل النظام بواجهة Microsoft Graph API ويجلب رسائل البريد الإلكتروني من صناديق البريد المُعدّة
2. **تحليل البريد الإلكتروني بالذكاء الاصطناعي** — يتم تحليل رسائل البريد الإلكتروني بواسطة الذكاء الاصطناعي لاستخراج:
    - اسم الشركة
    - دور جهة الاتصال
    - معلومات الاتصال
    - أرقام الهواتف
3. **إثراء الموقع الإلكتروني** — يتم فحص مواقع الشركاء ويستخرج الذكاء الاصطناعي:
    - عنوان العمل
    - قطاع الصناعة
    - تفاصيل أعمال إضافية
4. **المزامنة التلقائية** — يتم إنشاء أو تحديث سجلات الشركاء تلقائياً

### تتبع إثراء الذكاء الاصطناعي

انتقل إلى **شركاء الأعمال > تتبع إثراء الذكاء الاصطناعي** لمراقبة:

| العمود | الوصف |
|--------|-------------|
| **الشريك** | شريك الأعمال الذي يتم إثراؤه |
| **النوع** | عميل أو مورد |
| **الحالة** | جديد، قيد التنفيذ، مكتمل، أو فشل |
| **تاريخ الإنشاء** | وقت إضافة مهمة الإثراء للقائمة |

### سجلات عمليات الذكاء الاصطناعي

انتقل إلى **شركاء الأعمال > سجلات عمليات الذكاء الاصطناعي** لعرض سجل المراجعة الكامل:

| العمود | الوصف |
|--------|-------------|
| **نوع العملية** | نوع عملية الذكاء الاصطناعي المنفذة |
| **نوع الشريك** | عميل أو مورد |
| **بيانات الإدخال** | البيانات المرسلة للذكاء الاصطناعي |
| **بيانات الإخراج** | نتائج/استجابة الذكاء الاصطناعي |
| **الموظف** | الموظف الذي أطلق العملية |
| **تاريخ الإنشاء** | الطابع الزمني |

### الإثراء اليدوي

يمكن للمسؤولين تشغيل الإثراء يدوياً لشريك محدد عند الحاجة، بدلاً من انتظار دورة المهام التلقائية.

---

## سجل النشاط

يتم تسجيل جميع الإجراءات على شركاء الأعمال لأغراض المراجعة:

| الحقل | الوصف |
|-------|-------------|
| **الشركة** | الشريك المتأثر |
| **الإجراء** | إضافة، تحديث، حذف، أو استعادة |
| **المستخدم** | الموظف الذي نفذ الإجراء |
| **التاريخ** | الطابع الزمني للإجراء |

يمكن للمسؤولين **مسح سجل النشاط** عند الحاجة.

---

## الصلاحيات

يتم التحكم في الوصول إلى وحدة شركاء الأعمال من خلال الصلاحيات التالية:

| الصلاحية | الوصف |
|------------|-------------|
| **عرض** (عام) | عرض جميع شركاء الأعمال |
| **إنشاء** | إضافة شركاء أعمال جدد |
| **تعديل** | تعديل الشركاء الحاليين |
| **حذف** | حذف مؤقت للشركاء |
| **إجراء** | تنفيذ إجراءات عامة |
| **تغيير الحالة** | تغيير حالة العميل/المورد |
| **تحويل** | تحويل أنواع الشركاء |

!!! tip "صلاحيات المسؤول"
    يتمتع المسؤولون بوصول كامل لجميع الميزات بما في ذلك سجلات المحذوفات لمجموعات الأسماء، ومسح سجلات النشاط، وإعدادات الذكاء الاصطناعي.

---

## البحث الشامل

يتم تضمين شركاء الأعمال في البحث الشامل على مستوى النظام. اكتب اسم شركة في شريط البحث العلوي للعثور بسرعة على سجل شريك أعمال والانتقال إليه.
